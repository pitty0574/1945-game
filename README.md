# 空戰1945

縱向捲軸空戰射擊遊戲，操作戰機擊落敵機、挑戰每10關登場的Boss。

## 特色
- 支援手機觸控與電腦滑鼠鍵盤操作
- 武器升級系統(最高32階)，含追蹤飛彈、側翼砲、螺旋彈幕、蛇形彈、雷射光束等多種攻擊方式
- 右鍵雷射砲，寬度/傷害隨武器等級成長
- 每10關Boss戰，5種機型輪替、4種攻擊模式輪替
- 金幣連擊系統，正面拾取分數最高
- 10張背景照片依關卡輪替
- 單一HTML檔案，離線可玩

## 如何遊玩
直接用瀏覽器開啟 `index.html`，或部署到 GitHub Pages 後用網址開啟。
